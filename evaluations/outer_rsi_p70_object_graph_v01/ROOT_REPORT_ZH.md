## 实际方法

Root 从一条真实演示中提取抓持和放置关系，组成“定位与接近当前书 → 短抓持 → 抬离 → 定向 → 移到当前后格上方 → 接近入口 → 短 Insert”。每个阶段有独立的入口、完成、抓持保持和失败判断。Code 控制简单关系运动；抓持小模型输出短动作；原冻结 P68 Fast Adapter 仅在最后短 Insert 内更新 z。

新抓持头是 8→64→64→6 的 MLP：输入相对位姿误差与夹指状态，使用 3 万个合成关系误差教师样本训练 1200 次，另有 3000 个验证样本。它是本次真实新训练的模型，但不是新采集的 3 万条物理轨迹，也不是从 RGB 端到端训练。P68 视觉编码、动作模型和局部更新核心直接复用，未更改训练方法。

动作读取 RGB、可见实例 mask、相机标定、机器人本体状态与固定 demo／训练几何先验；持物后用抓持相对变换传播书本位置。独立 Boolean GT 判断抓持、间隙和完成；连续物体真值仅用于训练标签或封存后诊断。因而这仍是明确采用模拟器 mask 和 Boolean 监督的系统验证。

## 阶段验证与修订依据

- 原抓持前缀在 4 个预定训练初态都完成抬离。后续阶段使用这些真实前缀的完整场景快照；没有把物体手工摆到理想入口。
- 初次后段恢复有工程问题：物理状态恢复后，夹爪累计命令和控制器保持目标未同步；另有定向目标随当前物体漂移的问题。修正后两个真实后段均到达短技能入口。旧失败保留。
- Q3 训练 canary 四次均进入短 Insert，严格完成 2/4；另两次到预算末尾才出现目标关系，未满三帧保持。R2 增加独立 Code 确认，执行新的静止物理动作，不重写旧失败、不增加 P68 更新次数。
- R0 唯一失败的末端已接近估计目标，但实际书底比安全门低约 0.296 mm，末段已近乎停止上升。[诊断](R0_CELL003_DIAGNOSTIC.json)支持目标与交接条件不一致的解释。[R3](R3_RELATION_REFINEMENT_SCOPE.md)因此只在公开目标已到、Boolean 间隙仍不足时修订一次安全裕量，原判据不放宽。
- [R0/R1配对诊断](R0_R1_PAIRED_DIAGNOSTIC.json)发现五个退化回合全程保有双指接触、没有错误目标；改动后的持物变换与入口关系不同。它支持短技能对入口分布敏感的解释，但R1同时改变抓持顺序和固定校准，不能独立归责于其中一项。

## 验收与剩余边界

[最终服务器审计](final_v01/RETURN_AUDIT.json)核验全部36,584个封存文件，40次检测零程序错误、无自动重试；全部40个RESULT、SEAL和480个封存JSON/JSONL已回本机。Root另做[语义验收](final_v01/ROOT_SEMANTIC_AUDIT.json)：每个完整成功都对应三个不同时间的真实观测，原生初态恢复一次、后续恢复零次、整体720／短技能24动作上限均通过。四卡物理进程已经退出。

本轮科学验证关闭，不追加第四次外层更新，不把候选自动晋升为通用或真机能力。剩余大体积原始帧由一次性后台归档回传，运行状态／完成收据位于 `archive_return_v01`；这不改变已在服务器封存核验的结果，也不冒充本机已完整保存所有原始帧。

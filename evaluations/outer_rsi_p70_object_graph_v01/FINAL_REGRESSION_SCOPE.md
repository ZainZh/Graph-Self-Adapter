# P70 四版本冻结检测：结果前范围

本检测履行原计划的“每版另一组10次整任务检测”。R0、R1、R2、R3全部保留，各10次，共40次。采用原P69 test身份的初态 `[8,46,41,9,11,5,38,7,17,18]`，与本次10个explore初态不重叠；这些初态在历史P69中已打开，因此称另一组冻结回归检测，不称fresh held-out或新独立泛化。

每版从同一完整原生初态恢复一次，之后连续执行；没有中途恢复、自动重试、teacher接管、按检测结果换版本或训练。每个初态的执行seed为 `70030 + index`，四版本配对相同，开发使用 `70020 + index`。初态向量及hash由既有INIT_SCOPE和每版freeze绑定，随机seed不是替代初态定义。

四版各自使用开发时不可变源码、配置、模型与先验。R0源Q1b；R1源Q3；R2增加Code确认；R3回到R0的抓持先验并增加单次关系间隙修订和Code确认。所有版本总预算720、P68短Insert最多24；R2/R3可用最多3个新物理Code确认动作，仍在720内。成功判据全部保持原官方目标与连续三帧双指接触保持。

只有在四版本冻结后才允许启动检测。R3冻结之后即使开发结果不理想，也不追加第四次外层更新。检测的局部z仍按原P68允许更新，但图、Code、权重、固定校准与成功门全不变。

主结果为每版完整严格k/10，同时报告到达P68数量、原官方保持与瞬时目标、阶段失败、执行动作、适配更新、R3间隙修订触发和R2/R3确认贡献。前缀失败仍在分母中。主比较为R3对R0的配对救回/误伤，R1/R2过程结果完整呈现，不能只挑最好的版本讲成单调学习曲线。每个版本只有10次，报告有限样本事实，不用小幅差距声称确定的统计优越性。

开发成功最多的版本可作为后续推荐；如相同，优先已成功回合动作成本更低者，再优先较早版本。推荐依据在检测前记录，检测结果不再驱动此批候选修订。无论正负，本轮完成40次检测与审计后关闭。

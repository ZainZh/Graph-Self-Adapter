# P70：以物体关系定义阶段，先验证交接再组合长程任务

状态：2026-10-03，用户批准开发与模拟验证，结果未知。Root 负责拆图、实验判别和验收；执行助手负责实现、训练和有限队列。P69 已关闭，所有历史版本及结果不改写。

## 要回答的问题

同一条书本放入收纳盒的演示，能否通过以当前物体关系定义目标、用实际上游状态开发下游阶段，使完整任务可靠执行？本轮验证外层系统；不改变 P68 已冻结的短 Insert Adapter 内核，也不把完整流程的收益归因于梯度单独贡献。

## 从演示得到的图

原始任务仍为 LIBERO-10 `STUDY_SCENE1_pick_up_the_book_and_place_it_in_the_back_compartment_of_the_caddy`。沿用真实单演示 `data/sources/libero_one_shot_p48/book_demo_0.hdf5:data/demo_0`，SHA256 `92cf890a794a2c3bfe47cb68f0109f76901c3251f7331f6c03c10e258b30b94c`。演示提供相对抓持关系和目标关系的先验，不提供必须逐帧跟随的世界路径。

| 阶段 | 当前对象与目标 | 执行器 | 必须交给下游的状态 |
|---|---|---|---|
| 观察／张开 | 当前书与收纳格可定位，夹爪张开 | Code＋公开 mask 定位 | 有效当前物体估计；初始化沉降已结束 |
| 接近书 | 末端到当前书的抓持准备区 | 相对目标 Code | 进入短抓持模型的范围，夹爪仍张开 |

| 抬离支撑 | 已持书与桌面／障碍物有足够间隙 | Code | 保持抓持，允许下一阶段安全调整朝向 |

## 信息边界

- 普通动作输入：当前公开 RGB、模拟器可见实例 mask、已知相机标定、机械臂 proprioception、demo／训练得到的固定物体形状和关系先验。
- 允许初始视觉定位加抓持后刚性变换传播；必须说明这是持物假设，不能把预测的 attached 当成独立抓持证据。抓持与完成使用原先声明的 Boolean GT supervisor。
- 当前连续物体 GT 位姿只用于教师标签、开发诊断、封存后的测量；普通 Code、小模型和适配损失不能静默读取。若做 Oracle 诊断，独立标记，不混入候选成功率。
- 第一轮先做原生书形与位置变化；不同时引入尺寸估计、朝向 OOD、力度或质量研究。原生初态自带的朝向差异不计为新朝向 OOD。
- 新抓持网络和其教师监督、历史 P68 能力复用分别记账。合成关系误差训练不冒充真实机器人轨迹采集。

## 开发与验证顺序

1. 实现并检查相对目标、控制器与阶段判据。训练短动作头，离线误差仅作为实现检查。
2. 开发资格：至多 4 个预定训练初态完整前缀／阶段尝试。保存完整模拟器状态、公开估计、控制器状态与来源；阶段探索可从这些快照恢复，完整任务只在最初恢复一次。
3. 每个阶段从真实上游产生的入口进行短试，记录入口覆盖、阶段通过率和交接失败。保留完整场景及接触状态，不只放置末端到理想位置。
4. R0 和最多三个批间更新，各用相同 10 个开发初态连续执行完整任务。一轮可以协调修改图、Code、训练数据、模型和预算分配；每轮结果前冻结代码／配置／权重／seed，保留失败。若上游资格未通过，不盲目把 10 次整任务重复作为诊断，先在声明的阶段开发预算内定位，再冻结下一轮。
5. 全部待比较版本固定后，用另一组 10 个初态统一做完整检测，测试期间不改图、不改权重，仅允许短 Insert 内的 z 更新。P69 已打开的初态不再称全新 held-out。若使用新生成位置扰动，则先冻结生成器、数值范围、seed、完整初态 hash 和工程可行性规则，且独立报告为自定义 LIBERO 场景，不能冒充官方 benchmark 新测试。

开发初态：沿用 P69 explore 身份 `[21,49,19,33,23,39,14,44,40,42]`，全部是已开放开发。阶段资格先用 P69 train 的 `[20,2,12,26]`；物理次数、失败和工程错误全部保留。检测初态在资格完成后、检测结果开放前单独固定；不能根据检测表现选择版本。

## 有界预算与冻结

- 暂定每个完整回合共同上限 720 个执行动作，其中原 P68 短 Insert 仍最多 24；具体阶段上限随版本在结果前冻结。P69 原 544 步结果不能当作同预算直接配对收益。
- 阶段工程／探索最多 4 批、每批至多 16 次，独立阶段每次不超过 240 动作；进入完整开发批的前缀不再另算成阶段成功样本。
- 每版最多 10 个完整开发回合，最多 R0–R3；最终每版 10 个匹配检测回合。实现错误如零动作 abort 单列，不能静默重跑替换；任何修订使用新版本目录。
- 每 worker 独立 LIBERO 配置目录。四卡服务器有限队列，每 GPU 至多一个物理 worker；本机不做高并发渲染。不启动常驻监控。
- 没有阶段资格时可以得到失败结论，不以理想快照或 teacher 接管制造完整成功。完成全部预定工作后 Root 验收；未完成须明确剩余项目。

## 记录与结论

逐阶段入口／通过／失败、每版完整 k/10、耗时与动作数、Adapter 实际进入次数和更新次数分别记录。视频只选代表性完整成功／失败，标注阶段、目标与执行器。原官方成功和原稳定抓持保持门不放宽；瞬时成功单列。

本轮若有提升，只支持该任务与当前公开 mask／已知形状先验下的外层图和局部技能组合。不能据此声称从零 one-shot 学会、无真值感知、任意物体泛化，或 online 梯度优于所有替代方法。

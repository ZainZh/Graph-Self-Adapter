# Accepted cup task workflow

Run `./task_packages/put_mug_on_box_goalset_v25/run.sh --backend sim --check` for a zero-episode check, or `./task_packages/put_mug_on_box_goalset_v25/run.sh --backend sim` for one native engineering run. The shared frontdoor automatically creates a fresh scope/source snapshot, append-only reservation and result-free freeze. First grounding and UNKNOWN boundaries wait for the actual current Codex Agent; this is not unattended execution.

`--backend real --check` only constructs and checks lazy interfaces. Real execution is disabled; no device/deployment authorization is created by this package.

The accepted source uses actual SAM/metric RGBD, own feedback with unavailable actual aperture, bounded/fair simulator IO, and a current-entry joint/visible-support/yaw goal-set solver. It keeps the original neural weights, 20 mm observed release clearance, servo/endpoint limits and final original task/safety gate. The solver contains full observed2–98% cup contour within measured support with original10 mm planning margin and excludes the observed red contour. Its proxy is not hidden COM; planning is not a guarantee of exact physical clearance. White cup finished tilted and supported.

This package preserves exact runtime source snapshots, task graph/model/references and the Root acceptance. The launcher executes canonical repository sources, whose bindings are checked before startup. Standard simulator scenes, meshes, Python, SAM/SDK installations and private credentials remain external; rebind host configuration before another machine. This package is not a robot deployment. One opened nominal full task passed; no independent rate, generalization, gradient benefit or real task result is claimed.

The old yaw-only toy fixture is historical and invalid for the solver's six-dimensional orientation constraints. Its exact bound copy remains in source_snapshot/tests; the replacement full6DOF fixture is tests/test_cup_v25_current_goalset_kinematics.py. The former failure is documented rather than claimed as a passing test.
